## 게임 실행 방법
- 실행 환경 : wsl, 우분투 환경
- 설치 방법
  ```
  sudo apt update
  sudo apt upgrade
  sudo apt-get install libncurses5-dev libncursesw5-dev
  gcc Curvival.c -lncurses -lm
  ./a.out
  ```
  - 이미 Curvival이라는 실행 파일이 있긴 하다.
  - Ctrl + '+'로 화면 확대해서 플레이 하면 된다.
  - gameVersion은 지금까지 게임을 만들어왔던 과정들이 있다.
  - tempGame은 중간 점검 결과였다.
